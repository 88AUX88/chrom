## 画像認識 1回あたりの概算（未実測）
入力 ≒ 画像 1024px 約1,000 tok + カタログ20商品 約2,000 tok + 指示 約300 tok、出力（思考含む, effort=low）約500〜1,000 tok。
既定モデル claude-opus-5-5（$4/$20 per MTok）: 約 $0.013 + $0.01〜0.02。カタログ部分はプロンプトキャッシュ対象。
月100スキャンで 約$3〜4。`IDENTIFY_DAILY_LIMIT`（既定100回/日）で上限を設定。
より安いモデル（例 `IDENTIFY_MODEL=claude-haiku-5-5`）への変更は精度とのトレードオフのため利用者が判断する。
実際の消費トークンは scan_logs に記録し、設定画面に直近30日の概算を表示。正確な請求は Anthropic Console で確認。
API キーの発行・課金開始は **事前承認が必要**。

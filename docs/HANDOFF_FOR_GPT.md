## 1. 現状の一言
動作する MVP ソフトウェア（判定エンジン・取込・画面）は完成。**実データが未投入のため、実際の買付判断にはまだ使えない（未完成）**。

## 2. 実装済み機能
- SCAN: iPhone カメラ/アルバム → 端末で縮小 → カタログ制約付き LLM で最大3候補（API キー設定時のみ）。常に手動検索可
- PRODUCT: 素材・石・サイズ/長さを人間が選択して仕様（variant）を確定。誤認しやすい商品の警告
- PRICE: 国別正規価格（区分・税込/税別・確認日・出典・信頼性・古さ警告）
- MARKET: 同一仕様のみで 30/90日の成約件数・中央値・範囲・ばらつき（5件以上）。出品は参考表示のみ。売却率は算出不能と明示
- PROFIT: 3シナリオ・課税/免税ビュー・輸入税の端数処理・損益分岐・目標売価・最大仕入許容価格
- DECIDE: BUY/HOLD/PASS と理由・不足項目
- COMPARE: 仕入国比較（保守ROI順）・販売先比較（SNKRDUNK/BUYMA/買取）
- LEARN: 7日間カード（名称読み・誤認・素材/ルール・仮想利益計算）、間隔反復
- HISTORY: 判定保存・購入/販売記録・予想と実績の誤差、CSV/JSON エクスポート
- SETTINGS: 判定基準・経費・税前提・手数料（版管理）・為替・API費用概算
- IMPORT: 6種の CSV 検証取込（隔離理由表示）

## 3. 主要計算式
docs/CALCULATIONS.md を参照。要点:
- 課税価格（商業）= (支払 − 還付見込) × 為替 + 運賃 + 保険
- 関税 = floor100(floor1000(課税価格) × 率)、国消費税 = floor100(floor1000(課税価格+関税) × 7.8%)、地方 = floor100(国 × 22/78)
- 課税事業者: 売上・国内経費は税抜、輸入消費税は原価に含めない（控除）。免税事業者: 税込・輸入消費税は原価
- 区分不明時は両方計算し低い方。ROI = 税引前利益 ÷ 取得までの現金支出
- 売却シナリオは成約のみ（≥5件: P25/中央値/P75、少数: 最小値×(1−値引き) 等）。保守は為替+3%

## 7. セキュリティ上の注意
- 全ページ・API を middleware で保護（HMAC 署名 Cookie、30日）。APP_PASSWORD/SESSION_SECRET 未設定時はログイン不可
- 秘密情報はサーバー側のみ（NEXT_PUBLIC 変数なし、クライアントバンドルに秘密値が含まれないことを確認）
- 入力検証: zod / 厳密数値パース / 画像 data URL 形式・サイズ制限 / CSV 検証 / CSV 出力の数式インジェクション対策
- セキュリティヘッダー（nosniff, DENY, Referrer-Policy, Permissions-Policy）
- 画像認識は1日の回数上限で費用暴走を防止。AI 出力はカタログ内 ID のみ採用
- 未対応: ログイン試行のロックアウト（遅延のみ）、CSRF は Next.js Server Actions の Origin 検査に依存、監査ログなし

## 9. 評価してほしい判断
1. 判定ロジック: 「成約件数 3件以上 / 保守シナリオ（P25・為替+3%）で 利益1万円・ROI10%」という初期基準は、キャッシュ形成・在庫回避の目的に対して妥当か
2. 少数成約（1〜4件）のとき 最小値×0.9 を保守価格とする扱いは保守的すぎる/甘すぎるか
3. 課税価格に「還付されない現地売上税」を含める扱い（米国 sales tax 等）の妥当性
4. 課税事業者ビューで国際送料・旅費を消費税対象外として扱う前提の妥当性
5. 7113.11（銀）/7113.19（その他貴金属）の HS 区分マッピングで十分か（ダイヤ付き等）
6. 買取査定を「即時売却ルート」として保守価格の下支えに使う扱い
7. MVP の残作業の優先順位（docs/STATUS.md 末尾）

### この回で見つけて直した不具合
1. ルート直下の loading.tsx により、サーバーアクションの同一ページ redirect（仕様確定ボタン等）が反映されなくなる → loading は読み取り専用画面（candidates/market/compare/learn）のみに配置
2. React 19 のフォーム自動リセットで、商品追加の検証エラー時に入力が消える → 送信値を返して再表示
3. 本番ビルドではサーバーアクションのエラー文が隠れ、理由が分からない → 元の画面に戻して理由を表示、形式チェックはブラウザ側でも実施
4. jsonb のキー順の違いで、変更していない項目が変更履歴に記録される → キー順に依存しない比較
5. 型エラーを含むコミット（Observation.listedAt）→ 修正

### 独立監査（読み取り専用のサブエージェント）と修正
確認された11件をすべて修正し、回帰テストを追加:
1. 税別表示の米国定価を現地税0%で計算しBUYになり得た → 税率を確認するまで HOLD（買付計画で入力した税率は確認扱い）
2. 海外の成約が country 未指定で日本(JP)扱いになり国内判定に混入 → 海外通貨・海外販売先は country 必須、JP+外貨は拒否
3. サーバーアクションが未ログインでも /login 経由で実行可能 → 全アクションでセッションを検証（E2Eで未ログイン実行が書き込まないことを確認）
4. 経費を1項目だけ上書きして「確認済み」にすると全体が確定扱い → 全項目を上書きした場合のみ
5. 店頭確認価格が日付が古くても有効 → 記録日から判定（店頭確認は7日）
6. 未来日時の為替が永久に有効 → 取込で拒否、判定でも HOLD
7. 同じ取引IDの ASK と SOLD が重複扱い → 区別
8. 古い買取査定が保守価格に使われる → 有効日数（設定・既定30日）
9. 市場データの有効日数が判定に未反映 → 最新成約が古い場合に警告
10. 取り消しの再実行で記録を上書き・存在しないIDも履歴化 → 未取り消し行のみ更新
11. 戻り先URLのオープンリダイレクト → 同一オリジンのパスのみ
追加: 将来日付の手数料版を適用しない、二次流通サイトURLを公式定価として取り込まない、不正な率で例外にならない
未修正（要確認）: 関税額が1,000円未満の場合の切捨て（関税法の規定を一次資料で確認後に対応。現状は原価を多めに見積もる安全側）

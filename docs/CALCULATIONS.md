# 計算式（src/lib/profit/engine.ts）

すべて Decimal。円は表示・集計段階で四捨五入、税は下記の切捨て。

## 1. 現地購入
- 税込表示: 税抜 = 表示 ÷ (1+税率)、税 = 表示 − 税抜 / 税別表示: 税 = 表示 × 税率
- 現地支払 = 税抜 + 税、還付見込 = 税 × 還付率（設定。条件不明なら 0）
- 円換算 = 現地支払 × 為替（四捨五入）、カード手数料 = 円換算 × 率

## 2. 輸入（商業輸入 COMMERCIAL）
- 課税価格 = (現地支払 − 還付見込) × 為替 + 国際送料 + 保険（≒CIF）
- 関税 = floor100( floor1000(課税価格) × 関税率 )
- 消費税（国）= floor100( floor1000(課税価格 + 関税) × 7.8% )
- 地方消費税 = floor100( 消費税（国）× 22/78 )　※分数で厳密計算（浮動小数だと100円ずれる不具合をテストで検出・修正済み）
- 少額免税: 設定 ON かつ課税価格 ≤ 10,000 円 → 関税・消費税 0（対象外品目あり・要確認）
- PERSONAL（個人使用）: 課税価格 = 現地支払 × 為替 × 0.6。警告付き参考計算のみ。判定は常に HOLD。
- **前提**: 端数処理は国税通則法118・119条の一般的扱い。税関の公示為替レートとカード換算レートの差は未考慮。

## 3. 現金支出と利益
- 取得までの現金支出 = 円換算 − 還付 + カード手数料 + 国際送料 + 保険 + 通関手数料 + 関税 + 輸入消費税 + 旅費配賦
- 販売経費 = 手数料（売却×率＋固定）+ 国内送料 + 梱包費、リスク控除 = 売却 × リスク率（返品・値下げ）
- **免税事業者ビュー**: 売上=税込、取得原価=現金支出（輸入消費税を含む）
- **課税事業者ビュー**: 売上=税込÷1.1、取得原価から輸入消費税を除外（仕入税額控除）、通関手数料・送料・梱包・手数料も税抜。
  消費税精算見込 = 売上の消費税 − (輸入消費税 + 国内経費の消費税)。**二重計上しない**（テストで「免税CF − 精算 = 課税利益」を検証）
- 課税区分不明: 両方計算し低い方を採用し警告
- 粗利益 = 売上 − リスク控除 − 取得原価 / 販売経費控除後 = 粗利益 − 販売経費 / 税引前利益 = それ − その他経費（法人税・所得税は未考慮）
- 利益率 = 税引前利益 ÷ (売上 − リスク控除)、ROI = 税引前利益 ÷ 取得までの現金支出
- 税引前キャッシュフロー（消費税精算前）= 売却 − リスク控除 − 現金支出 − 販売経費(税込) − その他

## 4. 逆算（二分探索。端数処理で階段状でも単調）
- 損益分岐売却価格 / 目標利益に必要な売却価格: 利益 ≥ 目標となる最小の円
- 最大仕入許容価格: 保守シナリオで 利益 ≥ 最低利益 かつ ROI ≥ 最低ROI を満たす最大の現地価格（0.01 単位）

## 5. 売却価格シナリオ（src/lib/market/stats.ts）
同一 variant・同一状態グループ・期間内・sold_at あり の成約のみ（ASK は使わない）。重複除去後:
- 成約 ≥ 5件: 保守 = P25、標準 = 中央値、楽観 = P75（nearest-rank）
- 1〜4件: 保守 = 最小値 × (1 − 追加値引き)（買取査定が高ければそれ）、標準 = 中央値（仮定）、楽観 = なし
- 0件: 保守 = 買取査定の最高額（あれば）、他はなし
- 保守シナリオのみ為替を上振れ（既定 +3%）

## 6. 判定（src/lib/decide/engine.ts）
HOLD（BLOCKER）: 仕様未確定 / 仕入価格の根拠が店頭・公式・レシート以外 / 海外価格が古い / 為替なし・古い /
個人使用モード / 関税率未確認 / 手数料未確認 / 経費未確認 / 同一仕様の成約件数不足 / 保守利益が計算不能
PASS: 確認できた最高成約価格でも赤字、または成約件数が十分で標準シナリオでも基準未達
BUY: BLOCKER なし かつ 保守シナリオで 最低利益・最低ROI を満たす
基準値は設定画面で変更（初期値は仮置き: 1万円・10%・3件・90日）。

## 7. 関税率の選択（src/lib/profit/duty.ts）— 販売用の商業輸入のみ
- 関税は **原産国** で決まる。購入国（例: 米国の正規店で購入）とは別に保持し、異なる場合は画面に明示。
- HS コード: 買付計画で本人が設定（確定には根拠URL必須）。未設定時は素材から推定（銀 7113.11 / 金・白金 7113.19）＝「推定」。
- 協定（EPA）税率 `CUSTOMS_DUTY_RATE:HS:EPA:原産国`（EU加盟国は `EPA:EU` も参照）は
  原産国が「確定」かつ「原産性を証明できる」かつ税率が確認済みのときだけ適用。それ以外は一般税率 `CUSTOMS_DUTY_RATE:HS`。
- 関税率が「確定」でなければ BUY を出さない（HS 推定のままでも HOLD）。
- 個人使用の特例・簡易税率は使わない。

## 8. 消費税区分と控除（誤適用防止）
| 区分 | 輸入消費税 | 国内経費の消費税 | 売上の消費税 |
|---|---|---|---|
| 原則課税 TAXABLE | 控除（原価に含めない） | 控除 | 納付 |
| 簡易課税 SIMPLIFIED | **控除しない（原価に含む）** | 控除しない | 売上税額 ×（1 − みなし仕入率）を納付 |
| 免税 EXEMPT | 原価に含む | 原価に含む | なし |
| 不明 UNKNOWN | 原則課税と免税の低い方を採用 | | |
- 精算前の手残り = 売却 − リスク控除 − 現金支出 − 販売経費（税込）− その他
- 精算後の手残り = 精算前 − 消費税の納付額。全区分で「精算後の手残り = 税引前利益」となることをテストで検証。
- 簡易課税のみなし仕入率（DEEMED_PURCHASE_RATE）が未確認なら HOLD。

## 9. 確定値 / 推定値 / 未確認（src/lib/certainty.ts）
各項目は根拠のうち最も弱いものの区分を表示する。
- 仕入価格: 店頭確認・公式・レシート＝確定 / 購入者報告・推定＝推定 / なし＝未確認
- 為替: 有効時間内＝確定 / 古い＝推定 / なし＝未確認
- 関税: HS と税率（EPA の場合は原産国も）の最小 / 手数料・税前提: 確認済み＝確定、それ以外＝未確認
- 経費: 経費プロファイル確認済み＝確定、仮置き＝推定
- 概算利益・手残り・最大仕入許容価格: 予測のため最高でも「推定」
- 赤字リスク: 確認できた同一仕様の成約のうち損益分岐価格を下回る件数 / 総件数
